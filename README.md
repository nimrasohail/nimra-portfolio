# Nimra Sohail — Personal Portfolio

A complete responsive, static personal portfolio. No build tools required.

## Preview
Open `index.html` in your browser. For best results, serve the folder locally using `python -m http.server 8000` and visit http://localhost:8000.

## Publish for free
**GitHub Pages:** Create a public repository, upload `index.html`, `styles.css`, and `script.js` to the root, then go to Settings → Pages → Deploy from a branch → main / root. Your public URL will appear there.

**Netlify:** Drag and drop the whole `nimra-portfolio` folder into Netlify's manual deploy interface.

## Edit content
- Update text, links, and project descriptions in `index.html`.
- Change the color palette at the top of `styles.css`.
- Replace the generic GitHub link (`https://github.com/`) with your actual profile URL.
- The Fulbright chapter is written carefully to reflect a shortened program experience, without claiming a completed master's degree.
- No personal photographs or copyrighted images from the PDF are reused. The visuals are CSS-based and can be replaced with your own project photography.
- Fonts are loaded from Google Fonts; system fallback fonts will be used offline.
